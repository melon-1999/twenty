# 11 — User Complaints

**Date checked: 2026-08-09.** Public sources (G2, Capterra, Trustpilot, BBB, Reddit, review roundups). Aggregate ratings: G2 ~4.3/5 (~3,000 reviews), Capterra ~4.5/5, Trustpilot ~4.5/5 — **but BBB grade "D-"** (billing-dispute driven). Signal: users **love the pipeline UX and ease of use**, get frustrated by **cost creep, thin reporting, automation ceilings, and support/billing**.

Findings labeled RECURRING (across many sources — high confidence) vs ISOLATED (lower confidence).

## Recurring complaints

1. **Per-seat cost creep + add-on "nickel-and-diming" (MOST cited).** Base price looks cheap but the usable tier is Growth ($39), and core capabilities (lead gen, marketing, e-sign, web tracking) are separately-billed add-ons. "Pricing surprises once you scale." → **Opportunity: transparent, inclusive pricing.**
2. **Reporting is shallow / gated to higher tiers.** No native MRR/ARR; can't combine deal+activity+contact data in one report; no historical deal-movement trend; custom-field reporting locked to higher tiers; report count capped. → **Opportunity: real reporting out of the box.**
3. **Automation ceiling & rigidity.** Hard caps (50/150/250 workflows), ~10 actions per path, 90-day max runtime, no email-triggered automation, limited branching. Users fall back to Zapier (added cost). → **Opportunity: automation without artificial caps.**
4. **Customer support quality & billing disputes.** No phone support on lower tiers; slow resolution; charged after cancellation; charged for un-ordered add-ons with refund refusal; lockout with no phone fallback. BBB "D-". → **Opportunity: reachable human support + clean billing.**
5. **Email features & sync issues.** No email sync on Lite (one-way Smart BCC only); retro sync only ~6 months; Campaigns intermittently stops sending mid-campaign (reauth needed). → **Opportunity: reliable 2-way email in the base tier.**
6. **Mobile app weaker than desktop.** "Significantly harder to use than desktop." → **Opportunity: first-class mobile.**
7. **Deal-centric; weak post-sale.** No native account view/hierarchy, no post-sale lifecycle (onboarding/renewals/upsell). "Great for managing deals, not for managing customers." → **Opportunity: lightweight customer lifecycle beyond the deal.**

## Isolated / lower-frequency

- API/import limits (~10k records/day API cap; bulk contact cleanup cumbersome).
- Performance with very large databases.
- Learning curve for automation config (usually paired with "easy to use" praise → mixed).
- Marketing-automation inadequacy (overlaps with add-on/reporting themes).

## Top competitor opportunities (prioritized)

1. **Transparent all-in pricing** — bundle lead-gen, email, basic automation, basic reporting into the base seat; no add-on stacking. (Attacks #1.)
2. **Reporting that works out of the box** — MRR/ARR, cross-object reports, trends, custom-field reporting without a tier upgrade. (Attacks #2.)
3. **Uncapped, flexible automation** — email triggers, deep branching, no 50/10/90-day ceilings; no Zapier dependency. (Attacks #3, hidden Zapier cost.)
4. **Reachable support + clean billing** — trust-first message against BBB D-/Trustpilot billing threads. (Attacks #4.)
5. **Usable entry tier** — 2-way email + basic automation included, so buyers aren't forced into a 3× jump. (Attacks #1/#5.)
6. **First-class mobile.** (Attacks #6.)
7. **Customer lifecycle beyond the deal** — post-sale onboarding/renewals/upsell, account views. (Attacks #7.)
